## 错误码概览

### 错误码结构

```
NS-XXXYYY-ZZZ

示例: NS-001001-000

分解:
├── NS     - NetShare 前缀
├── 001    - 模块代码
├── 001    - 错误类型
└── 000    - 具体错误编号
```

### 模块代码

| 模块 | 代码 | 说明 |
|------|------|------|
| 系统 | 000 | 系统级错误 |
| 网络 | 001 | 网络通信错误 |
| 文件 | 002 | 文件操作错误 |
| 传输 | 003 | 传输相关错误 |

## 详细错误码

### NS-000001-001: 未知错误

**描述:** 发生了一个未知的内部错误。

**可能原因:**
- 未处理的异常
- 空指针访问
- 断言失败

**建议:**
1. 查看详细日志
2. 重启应用
3. 联系技术支持

**日志级别:** ERROR

---

### NS-001001-001: 连接失败

**描述:** 无法建立网络连接。

**可能原因:**
- 目标服务器不可达
- 网络配置错误
- 防火墙阻止

**建议:**
1. 检查网络连接
2. 检查目标服务器状态
3. 检查防火墙规则

**日志级别:** WARNING

---

### NS-001002-003: 请求过大

**描述:** 请求数据大小超过服务器限制。

**可能原因:**
- 上传文件过大
- 请求头过大
- POST 数据过大

**建议:**
1. 减小上传文件大小
2. 分块上传大文件
3. 调整服务器 `maxRequestSize` 配置

**日志级别:** WARNING

---

### NS-002001-001: 文件不存在

**描述:** 请求的文件在文件系统中不存在。

**可能原因:**
- 文件已被删除
- 路径错误
- 共享文件夹被移除

**建议:**
1. 检查文件是否存在
2. 刷新文件列表
3. 重新创建分享

**日志级别:** INFO

---

### NS-002004-001: 磁盘空间不足

**描述:** 磁盘可用空间不足以完成操作。

**可能原因:**
- 下载目录磁盘已满
- 临时目录磁盘已满
- 数据库磁盘已满

**建议:**
1. 清理磁盘空间
2. 更改下载目录
3. 清理临时文件

**日志级别:** ERROR

---

### NS-003002-001: 下载失败

**描述:** 文件下载操作失败。

**可能原因:**
- 网络中断
- 远程文件被删除
- 服务器无响应

**建议:**
1. 检查网络连接
2. 等待后重试
3. 使用断点续传

**日志级别:** ERROR

---

### NS-003005-003: 断点续传失败

**描述:** 尝试恢复下载失败。

**可能原因:**
- 服务器不支持 Range 请求
- 文件已被修改
- 缓存数据损坏

**建议:**
1. 重新开始下载
2. 清除缓存后重试
3. 联系管理员检查服务器

**日志级别:** ERROR

---

### NS-004002-002: Token 过期

**描述:** 访问令牌已过期。

**可能原因:**
- 长时间未操作
- 令牌超过有效期
- 系统时间被修改

**建议:**
1. 刷新页面重新获取令牌
2. 重新登录
3. 检查系统时间

**日志级别:** INFO

---

### NS-005001-002: 分享已过期

**描述:** 该分享链接已超过有效期。

**可能原因:**
- 超过设定的过期时间
- 分享创建者手动取消
- 超过最大下载次数

**建议:**
1. 联系分享创建者重新创建分享
2. 请求新的分享链接

**日志级别:** INFO

---

### NS-006001-001: 数据库连接失败

**描述:** 无法连接到数据库。

**可能原因:**
- 数据库服务未启动
- 数据库文件损坏
- 数据库路径错误

**建议:**
1. 检查数据库服务状态
2. 修复或重建数据库
3. 检查数据库路径配置

**日志级别:** CRITICAL

## 错误处理建议

### 1. 重试策略

| 错误类型 | 重试次数 | 重试间隔 | 最大等待 |
|---------|---------|---------|---------|
| 网络超时 | 3 | 1s, 2s, 4s | 7s |
| 连接失败 | 3 | 2s, 4s, 8s | 14s |
| 服务器错误 | 2 | 5s, 10s | 15s |
| 资源忙 | 5 | 1s, 2s, 4s, 8s, 16s | 31s |

### 2. 错误恢复

```cpp
// 自动恢复示例
void handleError(const NetShareError& error) {
    switch (error.category()) {
        case ErrorCategory::Network:
            if (error.code() == NS-001001-001) {
                // 连接失败，等待后重试
                retryWithBackoff(3);
            }
            break;

        case ErrorCategory::Transfer:
            if (error.code() == NS-003005-003) {
                // 断点续传失败，清除缓存重新下载
                clearCacheAndRestart();
            }
            break;

        case ErrorCategory::Auth:
            if (error.code() == NS-004002-002) {
                // Token 过期，重新获取
                refreshToken();
            }
            break;
    }
}
```

### 3. 日志记录

```cpp
// 错误日志格式
LOG_ERROR("Download failed: code={}, message={}, file={}, line={}",
          error.code(),
          error.message(),
          __FILE__,
          __LINE__);
```
