## CivetWeb vs cpp-httplib vs Drogon 详细比较
- 制作了交互式 HTML 对比报告（docs/civetweb_vs_httplib_vs_drogon.html）
- 获取了 C++ Web 框架基准测试数据（CSDN benchmarks）
- 三个框架核心差异：
  - CivetWeb: 功能够用、零成本迁移、Qt 兼容性最佳 → 短期推荐
  - cpp-httplib: 单头文件、API 极简优雅、阻塞 I/O QPS 仅 91 → 中期备选
  - Drogon: 性能最强 162K QPS、事件驱动、与 Qt 集成困难 → 不适合当前场景

## 四框架对比（加入 cpprestsdk）
- 新增 cpprestsdk (Casablanca) 对比分析
- 关键发现：cpprestsdk 同样 MIT 许可，HTTP/WS 功能较全，但微软已宣布维护模式，不推荐新项目使用
- cpprestsdk 依赖 Boost.Asio，无断点续传、无静态文件服务、无 SSE
- 综合评分：CivetWeb 7.40 > cpp-httplib 7.15 > Drogon 5.85 > cpprestsdk 4.85
