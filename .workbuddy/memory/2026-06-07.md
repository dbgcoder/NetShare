## 亮色主题导航选中状态修复
- **问题**：亮色主题下侧边栏导航（发送/接收/传输/LAN）无选中状态
- **根因分析**：
  1. `ListView.isCurrentItem` 在 QML `color: {}` 块表达式内绑定不可靠，导致选中背景色不更新
  2. 悬浮色 `hoverColor` 与侧边栏色 `sidebarColor` 对比度极低（`#e5e5e5` vs `#e8e8e8`），几乎看不见
  3. 初始 `currentIndex` 未设置，启动时首个导航项无选中
- **修改内容**：
  1. **Main.qml**：将全部 `ListView.isCurrentItem` 替换为显式 `readonly property bool isCurrent: menuList.currentIndex === index`
  2. **Main.qml**：新增左侧 accent 竖条指示器（`Rectangle width:3`），双重确认选中状态
  3. **Main.qml**：选中/悬浮逻辑分离——选中优先，悬浮仅在非选中时生效；三元表达式替代块表达式确保绑定可靠
  4. **Main.qml**：`Component.onCompleted` 中设置 `menuList.currentIndex = 0`
  5. **light.json**：`accentColor` `#0078d4` → `#106ebe`（Fluent UI 标准蓝）；`hoverColor` `#e5e5e5` → `#d6d6d6`（与 sidebar `#e8e8e8` 增加 10% 亮度差）

## 注册机杀毒误报修复
- **问题**：keygen.exe 被杀毒软件报毒
- **根因**：
  1. 可执行文件名 `keygen` 是 AV 黑名单关键词（与软件破解工具同名）
  2. RSA+SHA-256 加密操作+读取密钥文件+剪贴板操作，匹配勒索软件行为模式
  3. 无 PE 版本资源信息，未签名小体积 EXE 更易被启发式误判
- **修复**：
  1. 目标名 `keygen` → `NetShareLicense`，输出 `NetShareLicense.exe`
  2. 新增 `resource.rc` VERSION_INFO 资源（CompanyName/FileDescription/ProductVersion 等标准 PE 元数据）
  3. CMakeLists.txt 添加 `resource.rc` 到构建
  4. 窗口标题改为"NetShare 授权管理"
  5. 清理 dist/ 根目录下旧的 keygen.exe 和 VC 运行时 DLL

## 注册机窗口布局修复
- **问题**：注册码输出框底部被窗口边框截断
- **根因**：`WND_HEIGHT = 440` 包含了标题栏和边框，实际客户区仅约 394px，outputH 计算值偏大但实际可用高度不足
- **修复**：`WND_HEIGHT` 440 → 520，客户区高度增至约 474px，输出框底部不再被截断
